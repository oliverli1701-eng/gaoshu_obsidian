一些常见图表：

| 目标    | 方法                           |
| ----- | ---------------------------- |
| 折线图   | `ax.plot(x, y)`              |
| 散点图   | `ax.scatter(x, y)`           |
| 柱状图   | `ax.bar(categories, values)` |
| 直方图   | `ax.hist(data, bins=10)`     |
| 标题    | `ax.set_title("Title")`      |
| x 轴标签 | `ax.set_xlabel("X")`         |
| y 轴标签 | `ax.set_ylabel("Y")`         |
| 图例    | `ax.legend()`                |
| 网格    | `ax.grid(True)`              |
| 保存    | `fig.savefig("file.png")`    |
